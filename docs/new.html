安装一个插件

每个插件都支持两种来源：npm 预构建包（推荐，体积小、免构建），或 GitHub 源码（首次安装会请求构建授权）。命令复制自列表页，也可手动拼写。

# 从 npm 安装（预构建）
dsh plugin --profile web add <npm-package>

# 从 GitHub 源码安装（首次需按提示授权 allowBuilds 后重试）
dsh plugin --profile web add github:<owner>/<repo>

安全提示：GitHub 来源的插件安装时会在本机执行构建脚本，请只安装可信来源，并尽量锁定 commit（github:owner/repo#sha）。
